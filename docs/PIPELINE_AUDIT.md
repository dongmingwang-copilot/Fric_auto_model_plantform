# 主动学习 Pipeline 审计

## 当前严格流程

1. 导入未标注图像。
2. 使用当前 checkpoint 预测未 Review 图像。
3. 基于当前 checkpoint 的 probability map 生成主动学习队列。
4. 专业人士只 Review 队列中的样本。
5. 保存 Review 后覆盖该图该 label 的最新人工 mask。
6. 完成本轮队列后训练一次。
7. 训练只使用当前数据集全部已 Review 人工 mask，不使用未 Review 图像。
8. 训练完成后自动切换最新模型。
9. 用最新模型重新预测剩余未 Review 图像。
10. 重新生成下一轮队列。

## 为什么训练全部已 Review 样本

主动学习队列决定“本轮优先标哪些图”，不是训练过滤器。

训练使用全部已 Review 样本的原因：

- 新队列样本提供新的错误修正。
- 前几轮 Review 样本提供旧知识，防止模型遗忘。
- 未 Review 图像没有人工 GT，不进入训练。

因此不存在“Review 和未 Review 冲突”。真正需要避免的是把 prediction 当作 GT；当前平台不会这样做。

## 已修复的问题

- 模型下拉刷新时保留用户选择。
- 如果已有训练模型，页面初次加载默认使用最新训练模型。
- 训练完成后自动切换到 `run-{job_id}-best`。
- 训练完成后由后端服务自动仅预测未 Review 图像。
- 训练完成后由后端服务基于最新模型生成下一轮队列。
- 前端只显示后端 `next_cycle` 状态，不再负责关键写入，避免页面状态导致闭环断开。
- 已 Review 图像受保护，模型预测不会替换人工 mask。
- 生成队列时没有未 Review 候选则不创建空队列。
- 画笔不会因为重复涂抹而越来越红，显示透明度与已加载 mask 保持一致。
- 新增模型测试模块：选择模型后随机抽取已 Review 图像，使用最新版人工 GT 生成原图、GT、漏检/多检差异三联图。

## 仍需遵守的操作规则

- 不要在训练运行中继续修改同一数据集的 Review mask。
- 完成本轮队列后再训练，不建议每 Review 一张就训练。
- 每轮新模型训练完成后，旧队列作废，必须使用最新模型重新生成队列。
- 全部图像 Review 完成后，应最终训练并导出，或导入新图像进入下一轮。
